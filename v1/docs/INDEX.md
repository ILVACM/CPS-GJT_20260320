### 2.2 标准加载流程

```
1. 加载 AGENTS.md（全局权威，始终首先加载）
2. 加载 docs/INDEX.md（按需路由）
3. 按 INDEX 路由表定位目标文档
4. 仅加载目标文档（禁止一次性加载整个 docs/）
5. 如需引用其他文档，通过 INDEX 路由获取摘要，不直接加载全文
```

## 三、维护规则

1. **文件新增**：新文档创建后，在本索引"文档清单"中新增一行，并更新"路由指引"中相关条目。
2. **文件删除/归档**：从本索引中移除对应行；按 AGENTS.md §7.6 移至 `temp/`（项目唯一归档目录，与临时中间产物共处一目录）。
3. **文件移动/重命名**：更新本索引中对应行的"文件路径"列，并同步更新所有引用该路径的其他文档。
4. **内容重大变更**：更新"最后更新"日期与"可信度"状态。
5. **可信度状态更新规则**：
   - 文档与实际代码/配置核对一致 → `[已校验一致]`
   - 文档与实际不一致（已按实际修正） → `[存在差异]`
   - 无直接文档、基于客观线索推断 → `[推测]` / `[推断]`
   - 无任何线索 → `[待补充]`

## 四、可信度标签说明

| 标签 | 含义 | 人工复核建议 |
|------|------|-------------|
| `[已校验一致]` | 文档描述与实际代码/配置完全吻合 | 低优先级抽查 |
| `[存在差异]` | 文档与实际不一致，已按实际修正 | **高优先级复核** |
| `[推测]` | 无直接文档，基于客观线索推断 | 中优先级确认 |
| `[推断]` | 基于多处间接证据综合得出 | 中优先级确认 |
| `[待补充]` | 无任何线索，无法推测 | 需人工介入 |

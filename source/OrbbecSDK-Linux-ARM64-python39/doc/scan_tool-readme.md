# scan_orbbec_336l.py — 使用说明

## 工具简介

`scan_orbbec_336l.py` 是一个独立的奥比中光 Gemini 336L 设备参数扫描工具，用于快速诊断设备状态。与 `viewer.py`（实时显示 Demo）不同，本工具：

- **无 GUI 依赖**，可在 SSH 远程或 headless 环境运行
- **无需相机实时采集**，仅读取设备静态参数
- **输出结构化表格**，每个参数同时显示原始值与解析结果

**脚本位置：** `demo/3/source/scan_orbbec_336l.py`

---

## 依赖与安装

### 依赖清单

| 依赖 | 版本要求 | 安装方式 |
|------|---------|---------|
| pyorbbecsdk | >= 2.0.18 | `uv pip install source/pyorbbecsdk2-2.1.1-cp39-cp39-linux_aarch64.whl` |
| Python | 3.9+ | 系统 Python 或 uv venv |
| udev 规则 | 已安装 | `sudo ./source/install_udev_rules.sh` |

**注意：** 本脚本仅依赖 stdlib，无需 opencv、Pillow 等额外库。

### 安装命令

```bash
# 进入项目目录
cd /path/to/EBD-Orbbec/demo-3

# 激活虚拟环境
source ../.venv/bin/activate

# 安装 SDK wheel（如尚未安装）
uv pip install source/pyorbbecsdk2-2.1.1-cp39-cp39-linux_aarch64.whl
```

---

## 运行命令

```bash
# 从 demo/3 目录运行
python source/scan_orbbec_336l.py

# 或从项目根目录运行
python demo/3/source/scan_orbbec_336l.py
```

## 输出格式说明

### 三列表格含义

| 列名 | 说明 |
|------|------|
| **参数名称** | 人类可读的参数描述 |
| **原始字符串** | SDK/API 返回的原始值（保留引号、类型信息） |
| **解析结果** | 经过格式化、清洗后的可读值 |

### 原始字符串示例

| 参数 | 原始字符串 | 说明 |
|------|-----------|------|
| 设备型号 | `'Orbbec Gemini 336L'` | Python `repr()` 格式，显示引号 |
| PID | `2055` | 十进制整数（原始值） |
| PID（解析） | `0x0807` | 十六进制格式化 |
| 固件版本 | `1.8.10` | 字符串类型 |

## 常见问题

### Q1: 报错 `ImportError: No module named pyorbbecsdk`
- **原因：** venv 未激活或 wheel 未安装
- **解决：**
  ```bash
  source ../.venv/bin/activate
  uv pip install source/pyorbbecsdk2-2.1.1-cp39-cp39-linux_aarch64.whl
  ```

### Q2: 报错 `Bus error` 或 SDK 初始化失败
- **原因：** USB 权限不足
- **解决：** 安装 udev 规则
  ```bash
  sudo ./source/install_udev_rules.sh
  ```

### Q3: 未检测到设备
- **排查步骤：**
  ```bash
  lsusb | grep 2bc5          # 确认设备被系统识别
  dmesg | tail -20           # 查看内核日志
  python -c "from pyorbbecsdk import Context; print(Context())"  # 测试 SDK
  ```

### Q4: 深度流分辨率无法获取
- **原因：** 部分固件版本需要额外配置深度传感器
- **解决：** 检查 `source/99-obsensor-libusb.rules` 是否包含对应 PID 的 udev 规则

### Q5: 未找到目标设备（型号不含 "336L"）
- **现象：** 输出列出所有已检测设备，但无匹配项
- **解决：** 确认相机型号，修改脚本中的 `TARGET_KEYWORD` 常量

## 与 demo3 的关系

| 对比项 | `viewer.py` | `source/scan_orbbec_336l.py` |
|--------|-------------|------------------------------|
| **用途** | 实时 RGB 显示 Demo | 设备参数快速诊断 |
| **GUI** | 需要（tkinter） | 无 |
| **帧采集** | 持续采集（~30fps） | 不采集 |
| **输出** | 窗口 + 控制台日志 | 结构化表格（控制台） |
| **适用场景** | 开发调试 | 远程检查、设备验收 |

两者共享相同的 SDK 调用链，扫描脚本可视为 `viewer.py` 的"设备信息前置检查"工具。

## 五、备注

1. **固件版本限制**：本文档参数仅适用于固件版本 **1.8.10** 的设备。其他固件版本可能支持不同的分辨率或格式配置，需重新执行扫描校验。

2. **原始字符串 vs 解析结果**：
   - **原始字符串**：SDK/API 返回的原始值，保留 Python `repr()` 格式的引号和类型信息
   - **解析结果**：经过格式化、清洗后的可读值，用于人工理解和日志比对

3. **格式说明**：
   - `OBFormat.Y16`：16 位深度数据，每个像素 2 字节，数值单位为毫米 (mm)
   - `OBFormat.MJPG`：MJPEG 压缩的彩色图像，适合网络传输和实时显示

4. **校验方法**：其他项目在集成时，可运行 `source/scan_orbbec_336l.py` 获取当前设备参数，与本文档对照表逐项核对，确保 SDK 行为符合预期。
